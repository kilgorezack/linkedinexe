# LingoIn — The LinkedIn Lunatic Translator

Transform your normal human thoughts into maximally disruptive LinkedIn content.

## Setup

1. Clone the repo
2. Install dependencies: `npm install`
3. Copy `.env.local.example` to `.env.local` and add your Gemini API key
4. Run dev server: `npm run dev`
5. Open http://localhost:3000

## Deploy to Vercel

1. Push to GitHub
2. Import the repo in Vercel
3. Add `GEMINI_API_KEY` to Vercel environment variables
4. Deploy
